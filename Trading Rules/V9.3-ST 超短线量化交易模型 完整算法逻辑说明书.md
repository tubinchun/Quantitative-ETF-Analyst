## 📈 V9.3-ST 超短线量化交易模型 完整算法逻辑说明书

本说明书涵盖V9.3-ST模型的所有核心算法、因子定义、评分规则及决策流程，是模型的完整技术文档。


### 一、模型概述

#### 1.1 模型定位

V9.3-ST是一个多因子量化决策系统，专为**超短线及波段交易**设计，核心原则为 **“不追高、等回撤、分批建仓”** 。核心规则：每日14:50-14:55（闭市前）买入，次日9:30-10:30（开盘后）卖出（波段策略可参考建议持有天数）。模型通过五维评分体系结合附加因子，对全市场ETF进行量化评分，筛选次日上涨概率最高的标的。

#### 1.2 核心原则

- **不追涨**：任何买入指令必须通过F90追涨/抄底分类器与F73买点安全边际双重校验
- **只在回撤中买入**：标的必须处于“抄底区”（负乖离+回调），且产业逻辑未变
- **分批建仓**：采用“三批建仓法”，降低单一买点择时风险
- **极端行情自我保护**：当市场触发“暴雨航行”条件时，自动进入“极端生存模式”
- **纪律优先**：严格遵循尾盘买入、次日早盘卖出的规则，避免情绪干扰

### 四、信号生成层：五维评分体系（S1～S5）

```
Score = (S1 × W1 + S2 × W2 + S3 × W3 + S4 × W4 + S5 × W5) + AF
```

**基准权重**：W1=25%, W2=20%, W3=20%, W4=20%, W5=15%
权重由F67因子动态自适应加权系统与F70宏观状态机动态调整。

#### 4.1 S1 资金面（基准权重25%）

| 子因子                               |  权重  | 核心算法                                                     |
| :----------------------------------- | :----: | :----------------------------------------------------------- |
| 近5日净流入（时间衰减加权）          |  25%   | Z-Score = (当日净流入 - 近20日均值) / 近20日标准差；Z>2→10分 |
| 尾盘资金强度                         |  25%   | 尾盘30分钟净流入 / 近5日尾盘平均净流入；>1.5→10分            |
| 资金流结构                           |  15%   | 特大单净买入占比>60%→10分                                    |
| 资金加速度                           |  15%   | 当日成交额 / 近5日均成交额；>2→10分                          |
| 主力试盘信号                         |  10%   | 近3日加权平均试盘强度（T1×0.5+T2×0.3+T3×0.2）                |
| F10 资金-价格背离扣分                |  10%   | 资金流入但价格下跌，扣1-2分                                  |
| **F68-V2 主力资金行为分析**          |  修正  | 四分类：左侧机构布局(+3~+4分)、右侧机构追高(+1~+2分)、游资接力(+1~+2分且S5扣分)、散户跟风(扣分-1~-2) |
| **F92 主力承接意愿质量（V9.3新增）** | AF加分 | 恐慌承接+3分；左侧布局+1.5分；被动配置不加分；诱多承接直接剔除 |

**F92承接类型识别**：
- **恐慌承接**：指数/板块大跌（>3%）+ 主力资金逆势净流入 > 5亿 → +3分（高质量）
- **左侧布局**：缩量横盘 + 主力温和流入（1-5亿） → +1.5分（中质量）
- **被动配置**：ETF份额增加但个股主力流出 → 不加分（低质量）
- **诱多承接**：股价反弹 + 主力净流出 → **直接剔除**
