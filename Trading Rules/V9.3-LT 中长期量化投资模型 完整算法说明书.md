## 📈 V9.3-LT 中长期量化投资模型 完整算法说明书

本说明书涵盖V9.3-LT模型的所有核心算法、因子定义、评分规则及决策流程，是模型的完整技术文档。本模型定位为**中长期投资（持有周期3-12个月）**，所有参数均围绕此目标设计。

### 一、模型核心定位

#### 1.1 模型定位

V9.3-LT是一个**中长期多因子量化决策系统**，核心原则为 **“估值优先、产业为本、分批建仓、长期持有”** 。模型通过六维选股标准对ETF进行量化筛选，筛选符合“估值低位+产业向上+资金布局”三重条件的标的，建议持有周期为3-12个月。

#### 1.2 超短线→中长期 核心参数转换

| 对比维度     | 超短线策略      | **V9.3-LT中长期策略**       |
| :------- | :--------- | :--------------------- |
| **持有周期** | 次日清仓       | **3-12个月**             |
| **仓位上限** | 15%        | **70%**（极寒降至40%）       |
| **止损线**  | -3% \~ -5% | **-12% \~ -18%**       |
| **目标收益** | 3-5%       | **25-60%**             |
| **买入频率** | 每日尾盘       | **分批建仓，每月1-2次**        |
| **信号确认** | 单日触发       | **确认周期拉长至2-4周**        |
| **核心指标** | 超卖+资金当日流入  | **估值分位+产业趋势+ROE/盈利增速** |

#### 1.3 核心原则

- **估值优先**：PE/PB处于近5年30%分位以下才进入候选
- **产业为本**：行业必须处于景气上行周期，政策支持明确
- **分批建仓**：采用“四批建仓法”，降低单一买点风险
- **长期持有**：持有周期3-12个月，不因短期波动频繁操作
- **纪律优先**：严格遵循买入、持有、卖出规则

### 二、六维选股标准

#### 2.1 选股框架

```
综合评分 = 估值分位(35%) + 产业趋势(30%) + 盈利质量(15%) + 资金持续性(10%) + 催化剂密度(5%) + 价格位置(5%)
```

**入选条件**：综合评分 ≥ 7.5分，且至少满足4个维度

#### 2.2 维度一：估值安全边际（权重35%）

| 子因子      | 计算方法     | 评分规则                                              | 数据来源     |
| :------- | :------- | :------------------------------------------------ | :------- |
| **PE分位** | 近5年PE分位数 | <20%→10分；20%-30%→8分；30%-40%→6分；40%-50%→4分；>50%→0分 | Wind/理杏仁 |
| **PB分位** | 近5年PB分位数 | <20%→10分；20%-30%→8分；30%-40%→6分；40%-50%→4分；>50%→0分 | Wind/理杏仁 |
| **股息率**  | 当前股息率    | >5%→10分；4%-5%→8分；3%-4%→6分；<3%→4分                  | Wind/理杏仁 |

**估值安全边际得分 = PE分位得分 × 50% + PB分位得分 × 30% + 股息率得分 × 20%**

#### 2.3 维度二：产业趋势（权重30%）

| 子因子        | 计算方法      | 评分规则                                 | 数据来源       |
| :--------- | :-------- | :----------------------------------- | :--------- |
| **行业景气度**  | 行业营收/利润增速 | >20%→10分；10%-20%→8分；5%-10%→6分；<5%→4分 | 国家统计局/行业协会 |
| **政策支持**   | 政策层级与力度   | 国务院文件→10分；部委文件→8分；地方政府→6分；无→0分       | 政府官网/新闻    |
| **产业生命周期** | 行业所处阶段    | 成长期→10分；成熟期→8分；衰退期→0分                | 行业研究       |

**产业趋势得分 = 行业景气度 × 40% + 政策支持 × 35% + 产业生命周期 × 25%**

#### 2.4 维度三：盈利质量（权重15%）

| 子因子      | 计算方法      | 评分规则                                   | 数据来源 |
| :------- | :-------- | :------------------------------------- | :--- |
| **ROE**  | 近一年ROE    | >15%→10分；10%-15%→8分；5%-10%→6分；<5%→0分   | Wind |
| **营收增速** | 近一年营收同比增速 | >20%→10分；10%-20%→8分；5%-10%→6分；<5%→0分   | Wind |
| **毛利率**  | 近一年毛利率    | >40%→10分；30%-40%→8分；20%-30%→6分；<20%→0分 | Wind |

**盈利质量得分 = ROE × 40% + 营收增速 × 35% + 毛利率 × 25%**

#### 2.5 维度四：资金持续性（权重10%）

| 子因子         | 计算方法         | 评分规则                               | 数据来源         |
| :---------- | :----------- | :--------------------------------- | :----------- |
| **近60日净流入** | 60日主力资金净流入累计 | >0→10分；=0→5分；<0→0分                 | Level-2/东方财富 |
| **近20日净流入** | 20日主力资金净流入累计 | >0→10分；=0→5分；<0→0分                 | Level-2/东方财富 |
| **ETF份额变化** | 近60日份额变化率    | >10%→10分；5%-10%→8分；0%-5%→6分；<0%→0分 | 交易所数据        |

**资金持续性得分 = 近60日净流入 × 40% + 近20日净流入 × 35% + 份额变化 × 25%**

#### 2.6 维度五：催化剂密度（权重5%）

| 子因子      | 计算方法         | 评分规则                          | 数据来源  |
| :------- | :----------- | :---------------------------- | :---- |
| **近期催化** | 未来3个月内催化事件数量 | ≥3件→10分；2件→8分；1件→6分；0件→0分     | 财经日历  |
| **催化强度** | 催化事件影响力      | L1+级→10分；L1级→8分；L2级→6分；L3级→0分 | 新闻API |

**催化剂密度得分 = 近期催化 × 50% + 催化强度 × 50%**

#### 2.7 维度六：价格位置（权重5%）

| 子因子       | 计算方法      | 评分规则                                     | 数据来源 |
| :-------- | :-------- | :--------------------------------------- | :--- |
| **回撤幅度**  | 从年内高点回撤比例 | >30%→10分；20%-30%→8分；10%-20%→6分；<10%→0分   | 实时行情 |
| **均线乖离率** | 当前价与年线偏离度 | <-15%→10分；-15%\~-5%→8分；-5%\~5%→6分；>5%→0分 | 实时行情 |

**价格位置得分 = 回撤幅度 × 60% + 均线乖离率 × 40%**

### 三、综合评分公式

```
综合评分 = Σ(维度得分 × 权重)
```

| 维度     |  权重 | 评分范围 |
| :----- | :-: | :--: |
| 估值安全边际 | 35% | 0-10 |
| 产业趋势   | 30% | 0-10 |
| 盈利质量   | 15% | 0-10 |
| 资金持续性  | 10% | 0-10 |
| 催化剂密度  |  5% | 0-10 |
| 价格位置   |  5% | 0-10 |

**综合评分范围**：0-10分

**决策阈值**：

- ≥8.5分：强烈推荐配置（主力仓位）
- 7.5-8.4分：可配置（次主力仓位）
- 6.5-7.4分：谨慎参与（小仓位）
- <6.5分：暂不配置

### 四、仓位管理规则

#### 4.1 仓位上限

| 市场状态  | 触发条件                            |   仓位上限  |
| :---- | :------------------------------ | :-----: |
| 正常市场  | 综合评分≥7.5                        | **70%** |

| 政策底确认 | 政治局会议/国常会明确表态                   | **60%** |

#### 4.2 单方向仓位上限

| 方向评级 |   综合评分   |  单方向上限  |
| :--- | :------: | :-----: |
| 强烈推荐 |   ≥8.5分  | **25%** |
| 可配置  | 7.5-8.4分 | **20%** |
| 谨慎参与 | 6.5-7.4分 | **10%** |

#### 4.3 分批建仓节奏

| 批次      | 触发条件                          |   建仓比例  | 间隔要求 |
| :------ | :---------------------------- | :-----: | :--- |
| **第一批** | 符合选股标准+价格处于低位                 | **35%** | —    |
| **第二批** | 价格下跌5-10%（左侧加仓）或出现缩量企稳信号      | **30%** | ≥2周  |
| **第三批** | 出现放量中阳线（涨幅>2%+量比>1.5）或站上20日均线 | **25%** | ≥1个月 |
| **第四批** | 价格突破60日均线                     | **10%** | ≥2个月 |

| 超跌修复   |  6-12个月 | 30-40% | -15% |

#### 5.2 持仓监测指标（每季度评估）

| 监测项      | 标准       | 触发调整         |
| :------- | :------- | :----------- |
| **估值变化** | PE分位变化   | 分位>70%→考虑减仓  |
| **产业逻辑** | 政策/景气度变化 | 逻辑破坏→清仓      |
| **盈利验证** | 季报/中报/年报 | 连续不及预期→减仓    |
| **价格位置** | 偏离年线     | 偏离>+30%→考虑止盈 |

#### 5.3 卖出规则

| 卖出信号       | 具体标准           | 执行            |
| :--------- | :------------- | :------------ |
| **目标收益达成** | 累计涨幅达到目标区间     | 分批止盈（50%+50%） |
| **估值泡沫化**  | PE分位 > 80%     | 减仓50%         |
| **产业逻辑逆转** | 行业政策转向/基本面恶化   | 全部清仓          |
| **技术破位**   | 跌破年线且2个月内无法收回  | 减仓50%         |
| **时间止损**   | 持有超过18个月仍无正向反馈 | 全部清仓          |

### 九、使用注意事项

1. **中长期投资需承受更大波动**：持有周期3-12个月，期间可能经历10-20%的回撤，需有充分心理准备。
2. **估值是核心但不是唯一**：低估值不等于立即上涨，需结合产业趋势和资金面综合判断。
3. **分批建仓是关键**：不要一次性All-in，严格按照四批建仓法执行。
4. **每季度评估持仓**：重点关注估值变化、产业逻辑、盈利验证三个维度。
5. **达到目标收益及时止盈**：不贪心最后一分钱，分批止盈锁定利润。
6. **产业逻辑破坏立即清仓**：不要因为亏损而持有基本面变坏的标的。
